# **App Name**: Pill Pal

## Core Features:

- Prescription Image Upload: Allow users to upload an image of their prescription via drag-and-drop, file selection, or device camera.
- AI Prescription Analysis: Use a Genkit flow to extract medication details (name, dosage, schedule) from the uploaded prescription image.
- Dietary Suggestions: Use a Genkit flow tool to provide dietary suggestions based on extracted medication names (foods to eat/avoid).
- Health Tips: Use a Genkit flow tool to generate general health and lifestyle tips related to the extracted medication names.
- Medication Reminders: Allow users to set reminders for each medication, triggering a toast notification when the reminder fires.
- AI Medical Chatbot: Integrate a chatbot component to allow users to ask medical questions, providing responses with a disclaimer.
- Results Display: Display extracted medication details, dietary suggestions, and health tips in a multi-card layout.
- Medication Logging: Create a checklist below each medication to log daily intake. After completing the checklist, allow users to find nearby pharmacies using their location.

## Style Guidelines:

- Primary color: Soft blue (#90CAF9) for calmness and trust.
- Background color: Light gray (#FAFAFA) for a clean, modern look.
- Accent color: Teal (#4DB6AC) for call-to-actions and highlights.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral feel.
- Use simple, clean icons from ShadCN's icon library related to medications and health.
- Single-page layout with ShadCN components and Tailwind CSS for a clean, modern design.
- Subtle animations for loading states and user interactions to enhance the user experience.
